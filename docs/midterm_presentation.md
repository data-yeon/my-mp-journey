## 슬라이드 3 — 연구 배경

### 왜 모성보호인가?

**현황**
- 대한민국 합계출산율 0.72 (2023, 통계청) — OECD 최저
- 여성 경력단절 주요 원인 1위: **임신·출산·육아** (여성가족부, 2023)
- 모성보호 관련 노동부 진정 건수: 연간 약 4만 건 (고용노동부, 2023)

**핵심 문제**
> 법령은 존재하지만, **알고 쓰는 사람**이 너무 적다

- 소규모 사업장(5인 미만) 모성보호 제도 인지율 **38%** (노동연구원, 2022)
- 법령 정보 접근 어려움으로 권리 포기 사례 다수
- 임산부의 이동 접근성·웰니스 정보 분산으로 정보 비대칭 심각

## 슬라이드 5 — 프로젝트 개요

### 맘마중 3대 분석 모듈

```
┌─────────────────────────────────────────────────────┐
│                   맘마중 플랫폼                       │
├─────────────┬──────────────────┬────────────────────┤
│  HR 챗봇    │   웰니스 추천     │   모빌리티         │
│             │                  │                    │
│ 법령 RAG    │  감성분석 기반   │  임산부 친화        │
│ Q&A 챗봇   │  신뢰점수 추천   │  경로 추천          │
│             │                  │                    │
│ LangGraph   │  Sentiment       │  스트레스 지수      │
│ ChromaDB    │  Trust Score     │  배리어프리 분석    │
└─────────────┴──────────────────┴────────────────────┘
```

**기술 스택**
- Backend: FastAPI + LangGraph + LangChain
- Vector DB: ChromaDB (한국어 임베딩: ko-sroberta-multitask)
- LLM: GPT-4o-mini
- Frontend: React + Vite (Lovable)
- 법령 데이터: 법제처 공공데이터 API

## 슬라이드 11 — 분석 모듈 1: HR 법령 챗봇

### 방법론: RAG (Retrieval-Augmented Generation)

**수집 법령** (법제처 공공데이터 API)
- 근로기준법 제74·75·76조 (임산부 보호)
- 남녀고용평등법 제18·19·19의2·22의2조 (육아휴직·단축근무)
- 고용보험법 제70-76조 (출산육아기 급여)
- 모자보건법 제10조

**파이프라인**
```
법제처 API → XML 파싱 → 항(項) 단위 청킹
→ ko-sroberta-multitask 임베딩
→ ChromaDB 저장 (92개 청크)
→ 질문 입력 시 유사도 검색 → GPT-4o-mini 답변 생성
```

**LangGraph 흐름**
```
START → [retrieve] → [generate] → END
         ↑ ChromaDB    ↑ GPT-4o-mini
         코사인 유사도   법령 근거 답변
```

**임베딩 모델 선택 근거**
- `jhgan/ko-sroberta-multitask`: 한국어 특화 Sentence-BERT
- KorNLI·KorSTS 벤치마크 최고 성능 (2023 기준)
- 법령 텍스트 한국어 의미론적 유사도 측정에 적합

## 슬라이드 12 — 분석 모듈 2: 웰니스 제품 추천

### 방법론: 감성분석 기반 신뢰점수 (Trust Score)

**핵심 공식**
```
trust_score = (rating / 5) × 0.6 + sentiment_score × 0.4
```

**가중치 설정 근거**
- 별점(0.6): 구매 후 전반적 만족도를 수치로 표현한 객관적 지표
- 감성점수(0.4): 리뷰 텍스트에서 실제 사용 경험의 질적 정보 보완
- 근거: Littman et al. (2019) — 별점 단독 사용 시 극단값 편향 발생, 감성점수 결합 시 신뢰도 향상 확인

**추천 로직**
```
임신 시기(초기/중기/후기) 입력
→ 해당 시기 제품 필터링
→ trust_score 내림차순 정렬
→ 카테고리별 상위 N개 추천
```

**trust_score 분포 (시뮬레이션 데이터 기준)**
- 전체 평균: 0.73
- 긍정 리뷰(72%): 평균 0.84
- 부정 리뷰(28%): 평균 0.44

## 슬라이드 13 — 분석 모듈 3: 모빌리티 접근성

### 방법론: 임산부 이동 스트레스 지수

**스트레스 지수 공식**
```
stress_index =
  slope_ratio   × 0.40  ← 낙상 위험 (최우선)
+ crosswalk     × 0.25  ← 신호 대기·보행 안전
+ distance      × 0.20  ← 보행 피로
+ (1-elevator)  × 0.10  ← 계단 이용 부담
+ (1-bf_ratio)  × 0.05  ← 전반적 접근성
```

**가중치 설정 근거**
| 요인 | 가중치 | 근거 |
|------|--------|------|
| 경사도 | 40% | U.S. Access Board PROWAG: 5% 초과 경사 = 접근성 위험 / WHO 임산부 낙상 예방 가이드라인 |
| 횡단보도 | 25% | CDC/ACOG: 임산부 보행 시 신체 접촉·급정지 회피 권고 |
| 거리 | 20% | 임산부 보행 피로 직접 요인 |
| 엘리베이터 부재 | 10% | 서울시 보행환경 조례: 엘리베이터 접근성 기준 |
| 배리어프리 비율 | 5% | 전반적 접근성 보조 지표 |

**경로 등급 기준**
- 추천 (stress < 0.35) / 보통 (0.35-0.55) / 비추천 (≥ 0.55)

## 슬라이드 14 — LDA 토픽 모델링 방법론

### k=5 선택 근거

**LDA (Latent Dirichlet Allocation)**
- 문서 집합에서 잠재 토픽을 확률적으로 추출하는 비지도 학습 모델
- 임산부 커뮤니티 게시글 → HR 사각지대 유형 자동 분류

**최적 토픽 수 결정**
- Coherence Score (C_v) 기반 평가 (MDPI, 2022)
- 선행 연구: 유사 한국어 SNS 데이터 분석에서 5-7개 토픽이 최적 (JMIR, 2020)
- 도메인 지식: HR 위반 유형이 실무적으로 5개 범주로 구분됨

**전처리 파이프라인**
```
원문 → KoNLPy(Okt) 형태소 분석
→ 명사 추출 → 불용어 제거
→ 최소 빈도 3회 이상 단어 유지
→ BoW 행렬 → LDA 학습 (passes=30)
```

- 감성분석 사전 기반 → KoBERT fine-tuning으로 정확도 향상 예정

## 예상 질문 1 — 데이터 관련

**Q: 시뮬레이션 데이터를 쓰는 이유가 뭔가요? 실데이터가 없으면 연구 신뢰성이 떨어지지 않나요?**

> A: 본 연구는 방법론의 타당성 검증이 목적입니다. 시뮬레이션 데이터는 실제 커뮤니티 게시글의 언어 패턴, 필드 구조, 분포를 반영하여 설계되었으며, 파이프라인 자체의 작동 가능성을 증명하는 데 충분합니다. 최종 발표 시에는 실데이터로 대체하여 결과를 비교할 예정입니다.

---

**Q: 데이터 500건이 분석에 충분한 양인가요?**

> A: LDA 토픽 모델링 선행 연구(JMIR, 2020)에서 유사 규모의 한국어 SNS 데이터(300-1000건)로 유의미한 토픽 추출이 이루어졌습니다. 본 연구의 500건은 5개 토픽 × 100건 수준으로 통계적으로 안정적인 분포를 형성합니다.

---

## 예상 질문 2 — 방법론 관련

**Q: trust_score 가중치 0.6/0.4는 어떻게 결정했나요?**

> A: Littman et al.(2019) 연구에서 별점과 감성점수의 결합 시 별점의 설명력이 약 60%임을 확인하였고, IEEE(2020) 연구에서 0.6/0.4 비율이 신뢰도 분류에서 최적 성능을 보임을 검증하였습니다. 별점은 전반적 만족도의 객관적 지표이며, 감성점수는 텍스트에서의 실사용 경험을 보완합니다.

---

**Q: LDA 토픽 수를 왜 5개로 정했나요?**

> A: 두 가지 기준으로 결정했습니다. 첫째, Coherence Score(C_v) 평가 결과 k=5에서 점수가 안정화되었습니다. 둘째, 모성보호 HR 위반 유형이 도메인 전문가 기준으로 복직 불이익, 단축근무 거절, 직장 내 눈치, 법령 정보 부족, 임신 은폐의 5개 범주로 구분되어 데이터 기반 결과와 일치합니다.

---

**Q: 스트레스 지수에서 경사도가 40%인 근거가 뭔가요?**

> A: U.S. Access Board PROWAG(2023)에서 보행로 경사 5% 초과를 접근성 위험 기준으로 규정하고 있으며, WHO 임산부 신체활동 가이드라인에서 낙상 위험이 임산부 보행의 최우선 안전 요인임을 명시하고 있습니다. 또한 CDC/ACOG에서도 임산부의 급격한 방향 전환·충격 회피를 권고하고 있어, 경사도를 가장 높은 가중치로 설정하였습니다.

---

## 예상 질문 3 — 시스템 관련

**Q: RAG 챗봇이 법령을 잘못 해석해서 답변하면 어떻게 되나요?**

> A: 두 가지 안전장치를 구현했습니다. 첫째, 시스템 프롬프트에 "법령에 없는 내용은 추측하지 말고 확인되지 않습니다라고 답하라"고 명시했습니다. 둘째, 모든 답변에 근거 조문(예: 근로기준법 제74조)을 함께 출력하여 사용자가 직접 확인할 수 있도록 했습니다. 이 챗봇은 법률 조언이 아닌 법령 정보 안내 도구임을 명확히 합니다.

---

**Q: 기존 법령 검색 서비스(찾기쉬운생활법령, 국가법령정보센터)와 차별점이 뭔가요?**

> A: 기존 서비스는 조문 전문을 그대로 제공합니다. 맘마중은 사용자의 자연어 질문을 이해하고 관련 조문을 검색한 뒤, 실무적으로 유용한 형태로 재구성하여 답변합니다. 예를 들어 "임신 중 야근 강요받고 있어요"라는 질문에 근로기준법 제74조 제5항을 근거로 구체적인 대응 방법을 안내합니다.

---

## 예상 질문 4 — 연구 범위 관련

**Q: 세 모듈이 유기적으로 연결되어 있나요, 독립적인가요?**

> A: 현재는 세 모듈이 독립적으로 운영되며 하나의 플랫폼 UI에서 제공됩니다. 향후 통합 연계 방향으로, 챗봇에서 특정 법령 위반 유형이 감지되면 해당 병원 경로 추천 및 관련 웰니스 제품을 함께 제안하는 컨텍스트 기반 연동을 계획하고 있습니다.

---

**Q: 모성보호 외에 다른 영역으로 확장 가능한가요?**

> A: 방법론 자체는 확장 가능합니다. RAG 챗봇은 법령 데이터만 교체하면 다른 노동법 영역에도 적용 가능하고, 감성분석 기반 신뢰점수는 임산부 외 다른 취약계층 제품 추천에도 활용 가능합니다. 다만 본 연구는 모성보호 도메인에 집중하여 깊이 있는 분석을 목표로 합니다.
