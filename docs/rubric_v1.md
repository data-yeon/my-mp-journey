# 맘마중 HR 법령 RAG 답변 평가 Rubric v1

> 목적: 모성보호 법령 RAG 챗봇 답변을 LLM-as-a-Judge 및 Human Annotation으로 일관되게 평가하기 위한 초안  
> 평가 단위: 질문 1개에 대한 챗봇 답변 1개  
> 총점: 10점  
> 작성일: 2026-04-26

---

## 1. 평가 대상

각 평가 항목은 아래 입력을 기준으로 판단한다.

| 입력 필드 | 설명 |
|-----------|------|
| `question` | 사용자의 원문 질문 |
| `gold_answer` | 합성 데이터 생성 단계에서 만든 참조 정답 |
| `gold_sources` | 참조 정답의 근거 법령 조문 |
| `chatbot_answer` | 기존 RAG 챗봇이 생성한 답변 |
| `retrieved_sources` | 챗봇이 답변 생성 시 검색한 법령 조문 |

평가자는 `gold_answer`와 `gold_sources`를 우선 기준으로 삼되, 참조 정답 자체가 불충분하거나 법령과 충돌한다고 의심되는 경우 `needs_human_review=true`로 표시한다.

---

## 2. 평가 원칙

1. 답변의 말투나 친절함보다 **법령 내용의 정확성**을 우선한다.
2. 긴 답변이라는 이유만으로 높은 점수를 주지 않는다. 필요한 내용이 정확하고 간결하면 충분하다.
3. 답변이 참조 정답과 표현은 달라도 법령상 의미가 같으면 정답으로 인정한다.
4. 근거 법령이 명시되어 있더라도, 그 조문 내용이 질문과 맞지 않으면 법령 정확성 점수를 낮춘다.
5. 존재하지 않는 제도, 금액, 기간, 기관 연락처, 신청 절차를 확정적으로 말하면 할루시네이션으로 본다.
6. 실제 법률 자문처럼 단정적인 행동 지시를 하는 경우 감점한다. 예: "무조건 소송하세요", "반드시 승소합니다".
7. 질문이 모성보호 법령 범위를 벗어난 경우, 범위 밖임을 설명하고 관련 기관 상담을 안내하면 부분적으로 적절한 답변으로 볼 수 있다.

---

## 3. 채점 항목

### A. 법령 정확성: 0~3점

질문에 대한 법적 판단, 조문 내용, 적용 조건, 예외가 실제 법령 및 참조 정답과 일치하는지 평가한다.

| 점수 | 기준 |
|------|------|
| 3점 | 핵심 법적 판단이 정확하며, 조문 내용·조건·예외가 참조 정답과 충돌하지 않는다. |
| 2점 | 전반적으로 맞지만 일부 조건, 예외, 범위 설명이 부족하거나 약간 부정확하다. 사용자를 크게 오도하지는 않는다. |
| 1점 | 일부 맞는 내용이 있으나 핵심 조건을 잘못 설명하거나, 적용 대상·기간·급여 등 중요한 부분이 모호하다. |
| 0점 | 질문의 핵심 법적 결론이 틀렸거나, 실제 법령과 반대되는 내용을 답한다. |

예시 감점 기준:

- 임신 중 시간외근로 금지를 일반 야근 금지와 혼동함
- 육아휴직 적용 대상, 기간, 사업장 요건을 잘못 설명함
- 출산전후휴가 급여 지급 주체나 기간을 잘못 설명함
- 근로기준법, 남녀고용평등법, 고용보험법의 적용 범위를 혼동함

---

### B. 근거 명시: 0~2점

답변이 법령명과 조문 번호를 구체적으로 제시하고, 해당 근거가 답변 내용과 연결되는지 평가한다.

| 점수 | 기준 |
|------|------|
| 2점 | 법령명과 조문 번호를 구체적으로 명시한다. 예: `근로기준법 제74조`, `남녀고용평등법 제19조`. 근거와 설명의 연결도 자연스럽다. |
| 1점 | 관련 법령명만 언급하거나, 조문 번호 없이 "근로기준법상"처럼 포괄적으로 말한다. 또는 출처 목록은 있으나 본문 설명과 연결이 약하다. |
| 0점 | 법령 근거가 전혀 없거나, 존재하지 않는 조문·잘못된 조문을 근거로 제시한다. |

주의:

- 조문 번호를 많이 나열해도 질문과 무관하면 2점을 줄 수 없다.
- `retrieved_sources`에 근거가 있어도 `chatbot_answer` 본문에서 사용자가 이해할 수 있게 연결하지 않으면 최대 1점이다.

---

### C. 완전성: 0~3점

질문 해결에 필요한 핵심 요소가 빠짐없이 포함되었는지 평가한다.

| 점수 | 기준 |
|------|------|
| 3점 | 질문에 직접 답하고, 필요한 경우 대상자 요건, 기간, 절차, 예외, 실무적 다음 행동을 균형 있게 포함한다. |
| 2점 | 핵심 답변은 포함하지만, 조건·절차·예외 중 일부가 빠져 있다. 그래도 사용자가 기본 판단은 할 수 있다. |
| 1점 | 일반론 위주이며 질문의 핵심 상황에 충분히 답하지 못한다. 중요한 정보가 많이 빠져 있다. |
| 0점 | 질문에 답하지 않거나, 관련 없는 내용으로 회피한다. |

질문 유형별 완전성 체크포인트:

| 질문 유형 | 포함되면 좋은 요소 |
|-----------|-------------------|
| 출산전후휴가 | 휴가 기간, 출산 전후 배분, 다태아 여부, 급여 또는 신청 주체 |
| 육아휴직 | 대상 자녀 연령, 사용 기간, 사업주 거부 가능성, 불이익 금지 |
| 임신 중 보호 | 시간외근로 금지, 쉬운 업무 전환, 근로시간 단축, 태아검진 시간 |
| 급여 | 지급 주체, 신청 기관, 기간, 상한·하한 또는 조건 |
| 복직·불이익 | 불리한 처우 금지, 동일·유사 업무 복귀, 대응 절차 |
| 소규모 사업장 | 적용 가능 여부, 예외 가능성, 확인이 필요한 조건 |

---

### D. 할루시네이션 억제: 0~2점

법령 또는 참조 근거에 없는 내용을 만들어내거나, 불확실한 내용을 확정적으로 말하는지 평가한다. 이 항목은 "환각이 적을수록 높은 점수"다.

| 점수 | 기준 |
|------|------|
| 2점 | 근거 없는 법령·금액·기간·절차를 만들지 않는다. 불확실한 내용은 확인 필요하다고 표현한다. |
| 1점 | 답변의 핵심을 해치지 않는 작은 추정이나 부정확한 부가 설명이 있다. |
| 0점 | 존재하지 않는 법령, 조문, 지원금, 신청 기한, 기관 정보를 만들어내거나, 근거 없는 결론을 확정적으로 제시한다. |

즉시 0점 후보:

- 존재하지 않는 조문 번호를 인용함
- "5인 미만 사업장은 육아휴직이 절대 불가능하다"처럼 단정적으로 잘못 말함
- 법령에 없는 지원금 금액이나 전화번호를 만들어냄
- 사용자의 승소 가능성, 처벌 결과 등을 확정함

---

## 4. 총점 해석

| 총점 | 등급 | 해석 |
|------|------|------|
| 9~10점 | Excellent | 법령 근거가 정확하고 실제 서비스 답변으로 사용 가능 |
| 7~8점 | Usable | 대체로 사용 가능하나 일부 보완 필요 |
| 5~6점 | Needs Revision | 핵심은 일부 맞지만 사용자에게 제공하기 전 수정 필요 |
| 0~4점 | Fail | 법령 오류 또는 할루시네이션 위험이 커서 사용 부적합 |

---

## 5. 치명 오류 플래그

점수와 별도로 아래 플래그를 기록한다. 하나 이상의 치명 오류가 있으면 총점이 높더라도 최종 등급을 `Needs Revision` 이하로 조정할 수 있다.

| 플래그 | 의미 |
|--------|------|
| `wrong_legal_conclusion` | 핵심 법적 결론이 틀림 |
| `fabricated_source` | 존재하지 않는 법령·조문을 인용 |
| `unsupported_specific_claim` | 근거 없는 금액·기간·기관·절차를 단정 |
| `missing_core_condition` | 적용 대상, 기간, 예외 등 핵심 조건 누락 |
| `overconfident_legal_advice` | 승소, 처벌, 신고 결과 등을 과도하게 단정 |
| `out_of_scope` | 모성보호 HR 법령 범위 밖 질문 |
| `needs_human_review` | 참조 정답 또는 법령 해석 자체에 검토 필요 |

## 6. LLM Judge 출력 형식

Judge LLM은 반드시 아래 JSON 형식으로 출력한다.

```json
{
  "item_id": "string",
  "scores": {
    "legal_accuracy": 0,
    "evidence_citation": 0,
    "completeness": 0,
    "hallucination_control": 0
  },
  "total_score": 0,
  "grade": "Excellent | Usable | Needs Revision | Fail",
  "rationales": {
    "legal_accuracy": "string",
    "evidence_citation": "string",
    "completeness": "string",
    "hallucination_control": "string"
  },
  "fatal_flags": [],
  "confidence": 0.0,
  "needs_human_review": false
}
```

`confidence`는 0.0~1.0 사이 값으로 기록한다.

- 0.8 이상: 근거가 명확하고 판단이 쉬움
- 0.5~0.79: 일부 해석 여지가 있음
- 0.5 미만: 참조 정답, 법령 근거, 질문 의도가 불명확해 사람 검토 필요

## 7. Judge 프롬프트 초안

```text
당신은 대한민국 모성보호 HR 법령 답변을 평가하는 전문 평가자입니다.

아래 입력을 기준으로 챗봇 답변을 평가하세요.
답변의 문체나 길이보다 법령 정확성, 근거 명시, 완전성, 할루시네이션 억제를 우선 평가하세요.
참조 정답과 표현이 달라도 법령상 의미가 같으면 정답으로 인정하세요.
근거 없는 금액, 기간, 조문, 기관, 절차를 확정적으로 말하면 할루시네이션으로 간주하세요.

[질문]
{question}

[참조 정답]
{gold_answer}

[참조 근거]
{gold_sources}

[챗봇 답변]
{chatbot_answer}

[챗봇 검색 근거]
{retrieved_sources}

[평가 기준]
1. 법령 정확성: 0~3점
2. 근거 명시: 0~2점
3. 완전성: 0~3점
4. 할루시네이션 억제: 0~2점

반드시 JSON만 출력하세요.
```

## 8. Human Annotation 가이드

팀원이 직접 채점할 때는 아래 절차를 따른다.

1. 질문을 읽고 사용자가 실제로 알고 싶은 법적 쟁점을 한 문장으로 정리한다.
2. 참조 정답과 근거 조문을 확인한다.
3. 챗봇 답변에서 법적 주장, 조문 인용, 실무 조언을 분리해 본다.
4. 네 항목을 독립적으로 채점한다.
5. 치명 오류 플래그를 기록한다.
6. 판단이 애매하면 점수만 낮추지 말고 `needs_human_review`를 표시한다.

동일 답변을 2인이 채점한 뒤, 항목별 점수 차이가 2점 이상이거나 총점 차이가 3점 이상이면 토론 후 adjudication 점수를 만든다.

## 9. 예시 채점

### 예시 1. 좋은 답변

질문: "임신 중인데 회사가 야근을 시켜도 되나요?"

답변 요지: "근로기준법 제74조에 따라 사용자는 임신 중인 여성 근로자에게 시간외근로를 시킬 수 없습니다. 필요하면 쉬운 종류의 근로로 전환을 요구할 수 있습니다."

예상 점수:

| 항목 | 점수 |
|------|------|
| 법령 정확성 | 3 |
| 근거 명시 | 2 |
| 완전성 | 3 |
| 할루시네이션 억제 | 2 |
| 총점 | 10 |

### 예시 2. 위험한 답변

질문: "육아휴직 후 복직하면 원래 업무로 돌아갈 수 있나요?"

답변 요지: "회사는 인사권이 있으므로 어떤 부서로 보내도 문제 없습니다. 복직 보장은 법에 없습니다."

예상 점수:

| 항목 | 점수 |
|------|------|
| 법령 정확성 | 0 |
| 근거 명시 | 0 |
| 완전성 | 0 |
| 할루시네이션 억제 | 1 |
| 총점 | 1 |

치명 오류 플래그: `wrong_legal_conclusion`, `missing_core_condition`

## 10. 팀 논의 필요 사항

1. `gold_answer`를 법령 원문 기반으로 작성할지, 해설형 정답으로 작성할지 결정
2. 할루시네이션 항목을 0~2점으로 유지할지, 치명 오류 발생 시 총점 상한을 둘지 결정
3. Human Annotation 표본 수를 30개로 할지 50개로 할지 결정
4. 소규모 사업장, 공무원, 특수고용 등 적용 범위가 복잡한 질문을 별도 난이도 라벨로 둘지 결정
5. 판례·행정해석을 포함하지 않는 현재 RAG 범위에서 "완전성"의 최대치를 어떻게 제한할지 결정
